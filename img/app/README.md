# Product screenshots

Real screens from the Wedding Experts web app (`theweddingexperts-frontend`), captured 2026-09-15 from a local run against the local database, signed in through the local OAuth stub as a demo supplier.

The data is example data, localised for the UK at capture time: API responses were rewritten in the headless browser (UK places, GBP, English category names, supplier "Hartwell & Finch Photography") and nothing was written to the database. The gallery photos in the profile screens are the AI-generated placeholders from `img/` plus Unsplash images from the demo seed.
